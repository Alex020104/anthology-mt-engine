AOE Native Addons + HOTFIX6, 24.10.2026

Каталоги ниже содержат обновления для существующих аддонов Anthology.
Закрыть игру и MO2, сохранить предыдущие файлы и установить вместе с новым
движком AOE из текущей ветки. При копировании в mods объединить gamedata
с одноимёнными установленными аддонами; не удалять их остальные ресурсы.
Можно также собрать отдельный мод из нужных обновлений и поставить его
выше соответствующих оригиналов. Исходные аддоны должны остаться включены.

Файлы этого обновления находятся в каталогах:
- [AOE] Native Addons Core
- [[HUD] Interaction Dot Marks
- [HARD] SYS tactic_compass
- [GAM] Interactive PDA
- [GAM] Catspaw All Pack (каталог с исходным полным названием)
- [DBG] Kristiano Fixes ALL IN ONE
- [GAM] R.A.K Balance
- [UI] H.U.I. - Health User Interface
- [WPN] Weapon Cover Tilt (каталог с исходным полным названием)
- [WPN][1][SCP][R.A.K Weapon Pack Adaptation Global Anomaly 3DSS (OBT)]
- [GFX] Enhanced Shaders & Color Grading (полное исходное название)
- [GFX] ScreenSpaceShaders Update 23.5 (полное исходное название)

Остальные каталоги addon_overlays содержат ранее опубликованные совместимые
ресурсы. Не устанавливать отсутствующий у пользователя аддон только ради
его патча. Это не полная сборка модпака и не замена его порядка загрузки.

Core нужен для общих нативных запросов, обновления неба и меню DLSS/FSR.
Для ubgl_no_3db.script обязателен новый движок: защита настроек подствольника
перенесена в C++. Старые Lua-варианты из modpack-patches не должны перекрывать
эти файлы. Русские XML сохранены в исходной кодировке windows-1251.

Патч R.A.K включает только обработчики диалогов; основные модули снабжения,
настройки и ресурсы берутся из установленного R.A.K Balance.
Пользовательские конфиги, сохранения и профили в обновление не входят.
Состав изменений и ограничения проверок: docs/AOE_HOTFIX6_2026-10-24.md.
