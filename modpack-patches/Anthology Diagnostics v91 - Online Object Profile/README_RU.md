# Anthology Diagnostics v91 — Online Object Profile

Временный диагностический модуль для одного контрольного маршрута на базе.

- сохраняет `mt_task_manager 0` и рабочий `mt_ui 1`;
- включает `mt_frame_profile 1` и `mt_frame_profile_detail 1`;
- каждые 300 кадров движок пишет среднее время списка online-объектов,
  суммарное время `UpdateCL`, количество обновлений за кадр и самый дорогой
  section/объект;
- существующий профайлер дополнительно выводит самый дорогой scheduler-объект
  и задачу `seqParallel`.

Профиль делает вызов таймера вокруг каждого фактического `UpdateCL`, поэтому
его нельзя оставлять включённым для обычной игры или использовать как итоговый
замер FPS. После получения лога модуль отключается; оптимизация переиспользуемого
буфера объектов остаётся в движке и не меняет игровую логику.

Ожидаемый маркер:

`[anthology/v91] online object detail profile active; task manager MT disabled`
