# Anthology Performance v109 — MT UI Frame Sync

Исправляет мерцание Interaction Dot Marks и других быстро меняющихся HUD-
элементов при `mt_ui 1`.

Причина была в порядке кадра движка: прежний `ui_lock` не позволял обновлению и
отрисовке UI выполняться одновременно, но не гарантировал, что отрисовка дождётся
именно обновления текущего кадра. Иногда рендер успевал первым и показывал старое
состояние маркера, а на следующем кадре — новое. В движении это выглядело как
мигание.

V109 оставляет `pUIGame->OnFrame()` в игровом MT-потоке и сохраняет его
перекрытие с рендером мира. Перед показом HUD движок теперь ждёт публикацию
готового состояния UI текущего кадра. Полное ожидание всех вторичных задач не
добавляется.

Модуль включает `mt_ui 1`. Скрипты Dot Marks, PiP, SSS, A-Life, сохранения и
shader cache не изменяются. Новая игра и очистка shader cache не нужны.

Ожидаемый маркер в логе:

`[anthology/v109] MT UI current-frame synchronization active`
