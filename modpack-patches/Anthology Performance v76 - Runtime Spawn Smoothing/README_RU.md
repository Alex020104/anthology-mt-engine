# Anthology Performance v76 — плавная публикация спавна

Этот профиль включает ограничение только для спавна во время уже начавшейся
игры. Worker-поток продолжает заранее читать модели и готовить данные, а
главный поток публикует не более восьми подготовленных объектов за кадр.

Во время загрузки сохранения очередь по-прежнему обрабатывается полностью,
поэтому ограничение не добавляет искусственную задержку до получения контроля.
При необходимости размер игровой порции меняется командой
`spawn_antifreeze_max_per_frame` в диапазоне 1–128.
