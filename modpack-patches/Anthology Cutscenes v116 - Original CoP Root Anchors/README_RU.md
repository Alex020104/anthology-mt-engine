# Anthology Cutscenes v116 — Original CoP Root Anchors

Узкий патч поверх принятой v115. Камера, трава/details, диалоги, звук и тайминги сцен не изменяются.

## Причина

В оригинальном «Зове Припяти» первый клип NPC, привязанный к сценовому animpoint, запускался с абсолютной позицией и поворотом (`local_animation = false`). В Anomaly этот вызов изменён на локальный (`true`). Из-за этого старт сцены мог унаследовать root-transform предыдущей idle/walker-анимации: NPC подлетал, смещался или оказывался развёрнут не в авторскую сторону.

## Что изменено

- Для состава сцены спуска в Путепровод (`jup_b219`) и прибытия в Припять (`pri_a15`) восстановлен оригинальный абсолютный стартовый якорь CoP.
- Меняется только первый клип, у которого уже есть штатные `animation_position` и `animation_direction`.
- Все последующие moving-клипы продолжают использовать локальную цепочку root-motion, поэтому авторское движение и callbacks не обрезаются.
- Walker/remark NPC сцены `jup_b219` без штатного explicit anchor не телепортируются и не получают искусственную позицию. Старт сцены лишь ждёт, пока они реально достигнут authored waypoint, довернутся к authored look-point и сохранят стабильный XFORM 300 мс.
- Диагностируемый и аварийный LTX fallback срабатывают только через 30 секунд после штатных `on_pos`, поэтому неверный поворот не обходится ранним таймером, а повреждённое сохранение не зависает навсегда.
- Сохранены проверки готовности и стабильного XFORM из v115.

Патч не вызывает `set_position`, не телепортирует NPC, не меняет `moving`, `state_mgr`, анимационные списки, камеру, звук, диалоги или details.

## Проверка

Новая игра и очистка shader cache не нужны. Проверить сохранения перед спуском в Путепровод и перед переходом в Припять.

В логе должны быть строки:

```text
[anthology/cutscenes-v116] original CoP root anchor patch active
[anthology/cutscenes-v116] original CoP root anchor npc=...
[anthology/cutscenes-v116] JUP NPC XFORM settled
```

Для каждого затронутого NPC вторая строка печатается только один раз.
