# Anthology Diagnostics v102 — Actor Callback Attribution

Диагностическая надстройка над принятым движком v101. Движковые бинарники, трава v87,
A-Life/NPC, сохранения, загрузка, рендер, HOM/LOD, PiP и UI не изменяются.

Последний тест v101 показал:

- actor binder стабильно занимает примерно 2,5–3,5 мс кадра;
- spatial-поиск актёра после ограничения частоты занимает лишь около 0,004–0,013 мс
  за выполненное обновление и не может дать видимый прирост FPS;
- в `actor_on_update` зарегистрировано около 600 обработчиков;
- отдельный обработчик в выборке доходил примерно до 1,96 мс, но старый вывод
  `printf` не напечатал его имя из-за неподдерживаемых числовых спецификаторов.

Что исправлено в v102:

- строка отчёта целиком формируется стандартным Lua `string.format`, после чего
  передаётся движку одним `%s`;
- для функций и объектных callback извлекаются Lua-файл, строка и имя метода;
- рейтинг строится по средней цене одного вызова, а не по накопленной сумме;
- в заголовке отчёта отдельно указываются sampled/registered/frames;
- окно отчёта сокращено с 1800 до 1200 кадров, при этом за кадр по-прежнему
  измеряется только один обработчик.

Проверка: загрузить то же сохранение, 20–30 секунд походить по населённой базе и
нормально выйти из игры. В логе нужны строки `[anthology/v102/callback]`.
Новая игра и очистка shader cache не нужны.
