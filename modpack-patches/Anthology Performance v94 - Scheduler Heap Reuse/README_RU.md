# Anthology Performance v94 — Scheduler Heap Reuse

Изолированный вариант для постоянной нагрузки базы с большим количеством online-NPC.

## Что изменено

- v93 действительно обработала 3152 объекта за 1820,88 мс, но реальный тест не показал изменения.
  Первый полный проход A-Life удалён: он больше не увеличивает загрузку сохранения.
- Обычный scheduler обрабатывает на населённой базе примерно 200–250 объектов за кадр при batch 256.
  Раньше каждый обработанный объект пересоздавал структуру и повторно вызывал `shedule_Name()`, создавая
  лишний трафик `shared_str` даже с выключенным профилировщиком. v94 сохраняет исходный элемент очереди,
  меняет только два времени исполнения и перемещает его обратно без повторного получения имени.
- Выбор между `push_heap` и полной перестройкой heap теперь зависит от реального размера очереди и числа
  возвращаемых элементов. Для типичного случая `k=256`, `n≈3000` больше не перестраивается вся очередь
  каждый кадр.
- Порядок сроков scheduler, интервалы обновления, количество обработанных объектов, A-Life 150 м,
  позиции NPC, Lua, рендер, PiP, SSS и игровые скрипты не меняются.

Новая игра и очистка shader cache не нужны. Проверять следует на том же сохранении и маршруте.

Ожидаемый маркер:

```text
* [anthology/v94] scheduler item and adaptive heap reuse active; v93 sweep retired
```
