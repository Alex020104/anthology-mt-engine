# Anthology A-Life v105 — ранняя расстановка по работам смарта

Отдельный MO2-патч для NPC, которые после загрузки появлялись в общей точке
смарта и только затем расходились по назначенным работам.

- До запуска `setup_logic` создаётся неизменяемый снимок сохранённых вершин всех
  NPC смарта. Поэтому последовательная очистка `db.offline_objects` больше не
  ломает определение общей точки группы.
- Уникальная сохранённая позиция NPC восстанавливается без изменений.
- Если несколько NPC были схлопнуты в одну вершину центра, каждый ставится на
  вершину своей уже назначенной работы до активации рабочей логики.
- Если работа ещё не выбрана, используется штатный `select_npc_job`; существующие
  назначения и приоритеты не переставляются.
- Прибывающие к смарту отряды не телепортируются и продолжают обычный маршрут.
- Нет `actor_on_update`, периодического поиска или новых полей сохранения.

Патч заменяет `Anthology A-Life v80 - CoP Online Placement`; одновременно
включать обе версии нельзя. `Anthology A-Life v88 - 150m Budgeted Simulation`
остаётся включённым.

Новая игра не нужна. Для проверки надо полностью перезагрузить сохранение или
перейти на другую локацию. Маркер в логе:
`[anthology/alife-v105] prebound smart jobs active`.
