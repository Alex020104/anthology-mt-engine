# Anthology Performance v101 — Actor Callback Hotpath

Кандидат для проверки FPS на населённых базах поверх принятой основы v86 и
DX11-инстансинга травы v87.

Что изменено:

- движок обновляет поиск ближайших предметов/персонажей с частотой 30 Гц, а
  предупреждение о гранатах — 20 Гц; управление, физика, анимация и подбор
  предмета по клавише остаются отзывчивыми и выполняются штатно;
- диспетчер `actor_on_update` использует плотный кэш зарегистрированных
  обработчиков вместо обхода hash-таблицы и проверки типа каждого обработчика
  на каждом кадре;
- один обработчик `actor_on_update` за кадр измеряется ротационно. Это позволяет
  найти конкретный тяжёлый мод без установки таймера вокруг всех обработчиков и
  без заметного профайлерного штрафа.

Лог раз в 300 кадров показывает стоимость binder и spatial-поиска, а примерно
раз в 1800 кадров — двенадцать самых дорогих `actor_on_update` обработчиков.
Маркеры: `[anthology/v101/actor-binder]`, `[anthology/v101/actor-spatial]` и
`[anthology/v101/callback]`.

Сохранения, A-Life, положение NPC, рендер, качество травы, HOM/LOD, загрузка,
PiP и UI не изменяются. Новая игра и очистка shader cache не нужны.
