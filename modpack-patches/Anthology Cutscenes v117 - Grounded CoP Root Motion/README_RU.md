# Anthology Cutscenes v117 — Grounded CoP Root Motion

Узкий патч поверх v116 для двух сюжетных сцен Call of Pripyat: спуска в Путепровод (`jup_b219`) и прибытия в Припять (`pri_a15`). Камера, трава/details, звук, диалоги, тайминги и наборы анимаций не меняются.

## Исправленная причина

v116 применял абсолютный сценовый XFORM только когда первая анимация имела `moving = true`. На практике animpoint сначала включает обычный неподвижный idle. Штатный `state_mgr` уже на этом idle помечает `animation_direction_applied`, поэтому v116 больше не видел первый движущийся клип. Root-motion цепочка стартовала из старой walker/idle-матрицы: персонаж скользил, подлетал по Y или разворачивался не в авторскую сторону.

v117 восстанавливает оригинальный порядок CoP:

- первый клип с авторскими `animation_position` и `animation_direction`, включая idle, запускается абсолютно (`local_animation = false`);
- все следующие moving-клипы остаются локальными (`local_animation = true`) и продолжают штатную root-motion траекторию;
- изменение ограничено NPC и именами анимаций только двух проблемных сцен;
- NPC не телепортируются через `set_position`, а физика и общий движковый контроллер анимационного движения не подменяются.

Для сцены на Юпитере также исправлена проверка patrol path: точка теперь читается напрямую через штатный `patrol(...)`. Ненадёжный предварительный `level.patrol_path_exists` больше не может удерживать чёрный экран 30 секунд, когда путь фактически существует.

## Проверка

Новая игра и очистка shader cache не нужны. Нужны сохранения перед спуском в Путепровод и перед переходом в Припять.

В логе ожидаются строки:

```text
[anthology/cutscenes-v117] grounded CoP root-motion patch active
[anthology/cutscenes-v117] grounded CoP root anchor npc=... moving=false local=false
[anthology/cutscenes-v117] JUP NPC XFORM settled
```

Ключевая проверка — строка `root anchor` должна появиться для каждого animpoint-участника сцены, а не только для Зулуса.
