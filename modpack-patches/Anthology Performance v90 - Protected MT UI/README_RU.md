# Anthology Performance v90 — Protected MT UI

Стабилизационный модуль после эксперимента V89.

Что делает:

- возвращает `mt_task_manager 0`: менеджер активных заданий игрока снова
  обновляется на основном потоке;
- сохраняет `mt_ui 1`: `pUIGame->OnFrame()` выполняется в существующем игровом
  MT-потоке; обновление и рендер UI синхронизированы движком через `ui_lock`, а
  `CustomStatics` защищены собственной блокировкой;
- сохраняет `lua_use_functor_cache 1`;
- выключает встроенный MT-профайлер в обычной игре, чтобы измеритель сам не
  участвовал в тесте FPS. Для диагностического заезда его можно временно
  включить консольной командой `mt_frame_profile 1`.

Модуль не переносит NPC AI, smart-terrain или A-Life на другой поток. Новая
игра и очистка shader cache не требуются.

Ожидаемый маркер в логе:

`[anthology/v90] protected MT UI active; task manager MT disabled`
