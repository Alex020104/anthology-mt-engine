# Anthology Diagnostics v99 — Base Frame Breakdown

Диагностический патч для стабильной базы v86 с оптимизацией травы v87.

Он не меняет игровую логику, A-Life, дистанции, рендер или настройки качества. Патч включает подробный профайлер и раз в 300 кадров записывает в `xray_chenc.log`:

- стоимость каждого обработчика основного `seqFrame`;
- стоимость объектов и HUD;
- суммарную стоимость `UpdateCL` и самый дорогой объект;
- сетевую часть, карту и задания, Lua-скрипты, GC, звук и вложения;
- уже существующую разбивку рендера и фоновых потоков.

Для замера достаточно загрузить ту же сохранённую игру, пройти обычным маршрутом по Скадовску/базе 1–2 минуты, один раз открыть диалог с NPC и корректно выйти из игры.
