# Anthology Performance v72 — Regression Rollback

Патч устраняет измеренный регресс v70/v71 без изменения скриптов и состава
MO2.

## Что исправлено

- Обязательная прогрузка мира отключена (`load_world_warmup_ms 0`). В свежем
  логе она добавляла к каждой загрузке ровно 5019 мс. Сам механизм сохранён в
  движке и при необходимости может быть включён вручную.
- Возвращён проверенный в v66 режим перекрытия Lua GC с рендером: шаг 75,
  максимум 25 вызовов и бюджет 5000 мкс. Lua VM не переносится на конкурентный
  поток: GC выполняется после script workers на GameThread, пока основной поток
  занимается рендером.
- Возвращён сбалансированный SSFX-профиль. В активном `user.ltx` снова стояли
  тяжёлые AO 8, IL 32, SSR 4, SSS 18/6 и POM 36, а свежий профиль показывал
  22–25 мс только на рендер.
- `r__hom_dynamic` оставлен выключенным: покомпонентный dynamic HOM дублирует
  существующий тест renderable и ранее увеличивал CPU-пики.
- Ограничение 60 FPS применяется только к меню; игровой FPS не ограничен.

## Установка и проверка

Движок уже собран и установлен в двух вариантах: обычный DX11 и DX11-AVX.
Файл `user_runtime_profile.ltx` является точной копией изменяемой части
активного профиля и нужен для аудита/восстановления настроек.

Новая игра и очистка shader cache не требуются. Проверять нужно на том же
сохранении. Самостоятельно запускать игру при подготовке патча не выполнялось.
