# Anthology Performance v73 — Adaptive Frame / LOD / HOM

Версия v73 убирает регресс v72 с тяжёлой работой сразу после появления мира и
добавляет безопасные оптимизации LOD/HOM. Она не меняет сохранения и не требует
новой игры или очистки кэша шейдеров.

## Что исправлено

- Отключён дублирующий callback из `aaaa_script_fixes_mp`, который после
  загрузки дважды выполнял полный `collectgarbage("collect")` и затем
  `jit.flush()`. В контрольном логе этот блок занял около 1,77 секунды и
  останавливал первые видимые кадры. Исходный скрипт модпака не изменён:
  callback снимается отдельным совместимым патчем.
- Пошаговый Lua GC остаётся на потоке-владельце Lua VM, но теперь работает
  адаптивно: не запускается первые 8 секунд после готовности мира, пропускает
  уже перегруженные кадры и не начинает шаг, если окно перекрытия с рендером
  закончилось. Лимит одного кадра снижен с 5 мс/25 вызовов до 1,2 мс/6 вызовов.
- В лог добавлена разбивка GameThread на scheduler, `seqParallel` и
  `seqFrameMT`, плюс счётчики выполненных и пропущенных шагов GC. Это позволит
  найти оставшийся источник тиков по фактам, а не по общей загрузке ядер.
- HOM теперь повторно использует результат теста в пределах одного конкретного
  render-view. Основная камера и PiP имеют разные маркеры, поэтому результат
  скрытия из основной камеры не может скрыть объект в PiP. Дистанция HOM-
  треугольников вычисляется один раз до сортировки, а не на каждом сравнении.
- Для LOD выбор трёх лучших граней импостора сделан линейным проходом вместо
  восьмиэлементной сортировки каждый кадр. Исправлена индексация при нескольких
  vertex-buffer batch и защита от нулевой ёмкости batch.
- Активный переход LOD изменён с вырожденного `50/50` на `56/48`, а общий
  `r__geometry_lod` — на `0.85`. Это создаёт нормальную зону плавного перехода
  и немного раньше включает дальнюю геометрию без резкого pop-in.
- Экспериментальный `r__hom_dynamic` оставлен выключенным: он повторяет
  существующий HOM-тест для дочерних visual и в этой ветке ранее давал лишние
  пики CPU.

## Активные параметры

```text
load_world_warmup_ms 0
lua_gcstep 300
lua_parallel_gc 1
lua_parallel_gc_adaptive 1
lua_parallel_gc_budget_us 1200
lua_parallel_gc_call_amount 6
lua_parallel_gc_debug 0
lua_parallel_gc_frame_budget_us 12000
lua_parallel_gc_postload_delay_ms 8000
lua_parallel_gcstep 10
r2_ssa_lod_a 56.
r2_ssa_lod_b 48.
r__geometry_lod 0.85
r__hom_dynamic off
```

## Как проверить

Загрузить ту же сохранённую игру и пройти тем же маршрутом. В новом логе должна
быть строка:

```text
~[Anthology v73] redundant post-load full Lua GC/JIT flush disabled
```

После неё не должно быть строки
`~[luagc_cleanup] collectgarbage before`. Новые строки
`[mt-frame/profile] game-breakdown` покажут среднее/максимум scheduler,
`seqParallel`, `seqFrameMT` и причины пропуска GC.

Если результат не устроит, полный снимок v72 находится в
`E:\ANTHOLOGY_BACKUPS\20260821_v73_pre_adaptive_lod_hom`.
