# Anthology Cutscenes v110 — CoP Cinematic Sync

Узкий патч сюжетной цепочки «Юпитер → Путепровод → Припять».

- Убирает двойной запуск одного и того же звука открытия гермодвери перед Путепроводом. Звук остаётся привязан к самой анимированной двери.
- Возвращает оригинальный `npc_sound` для сюжетных реплик `jup_b219`, `pas_b400` и `pri_a15`. Обычный фикс остановки реплик умерших NPC продолжает работать во всех остальных сценах.
- Не применяет дополнительный camera hold/easing между частями оригинальных камер `jup_b219_descent_camera` и `pri_a15_cameffector`.
- Исключает сюжетных NPC этой цепочки из одноразовой перестановки A-Life v108. Их положение снова определяет оригинальная логика сцены.
- Исправляет дублированный ключ `on_info2` при входе в сцену Припяти.

Новая игра, очистка shader cache и замена движка не нужны. Для проверки загрузить сохранение до спуска в Путепровод и пройти переход целиком.

Ожидаемые исправления: звук двери без эха/фазирования, реплики остаются у говорящих NPC, камера не получает искусственные паузы, NPC после Путепровода не переставляются A-Life-патчем между кадрами.
