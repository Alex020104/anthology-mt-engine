# Anthology Diagnostics v100 — Persistent/A-Life Breakdown

Тестовый модуль для принятой базы v86 с DX11-инстансингом травы v87.
Игровую логику, A-Life, дистанции, NPC, рендер, загрузку и качество изображения
не меняет.

Раз в 300 кадров лог дополнительно показывает:

- стоимость окружения, realtime scheduler, погоды и DOF внутри `CGamePersistent`;
- число RT-объектов и самый дорогой из них;
- отдельно `A-Life switch` и `A-Life scheduled`;
- самый дорогой offline A-Life объект с ID, секцией и именем.

Для замера загрузите ту же сохранённую игру, походите 1–2 минуты внутри
населённой базы, один раз откройте диалог NPC и корректно закройте игру.
Ожидаемый маркер: `[anthology/v100] persistent and A-Life breakdown active`.
