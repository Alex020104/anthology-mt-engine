# Anthology Performance v97 — Remote A-Life Pacing

Отдельный тестовый патч для обнаруженного профилировщиком источника регулярных тиков: тяжёлого Lua-обновления удалённых offline A-Life отрядов.

Что изменено:

- нативное перемещение каждого отряда по game graph продолжает выполняться на каждом штатном A-Life обновлении;
- полная Lua-цепочка `refresh / condlist / callbacks / target selection` для offline-групп дальше 300 метров либо на другой локации выполняется раз в 5–7 секунд;
- интервал сдвинут по ID отряда, поэтому удалённые группы не создают общий импульс в одном кадре;
- online-группы и группы в пределах 300 метров работают с исходной частотой;
- сюжетные, companion-, `force_online`- и явно scripted-target группы также всегда работают с исходной частотой;
- A-Life online/offline радиус 150 метров, позиции NPC и формат сохранений не изменены;
- PDA-метки удалённых групп больше не вызывают несколько бесполезных переходов Lua → engine;
- неизменившаяся fallback-задача `CALifeSmartTerrainTask` переиспользуется вместо создания нового luabind userdata на каждом обновлении.

Патч не переносит Lua VM или A-Life на чужой поток: состояние симуляции остаётся последовательно и безопасно для сохранений.

Маркер в логе:

```text
* [anthology/v97] remote offline A-Life pacing active
```

Для теста подходят существующее сохранение и тот же маршрут по тяжёлой базе. Новая игра не нужна.
