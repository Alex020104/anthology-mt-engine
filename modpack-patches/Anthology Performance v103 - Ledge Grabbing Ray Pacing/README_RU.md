# Anthology Performance v103 — Ledge Grabbing Ray Pacing

Отдельная MO2-надстройка над установленным Ledge Grabbing.

- Ограничивает дорогую проверку поверхности и веер геометрических лучей частотой 30 Гц.
- Значение MCM выше 33 мс по-прежнему соблюдается; ошибочное значение `0` больше не запускает до 15 лучей каждый кадр.
- Само перемещение, анимация, высота, дальность, число лучей и условия паркура не изменены.
- Сохранения не меняются. Новая игра не нужна.

Проверка: в логе должна появиться строка `[anthology/v103/ledge]`, после чего нужно проверить обычный подъём на уступ. Откат — отключить только этот аддон в MO2.
