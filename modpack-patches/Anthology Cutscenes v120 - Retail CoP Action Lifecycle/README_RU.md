# Anthology Cutscenes v120 — Retail CoP Action Lifecycle

Узкий накопительный патч для сюжетных сцен `jup_b219` и `pri_a15`. Он исправляет
перемещение NPC на уровне логики запуска оригинальных анимаций Call of Pripyat.

## Что установлено точно

- Модели и OMF-анимации исправны: набор движений и длительность совпадают с CoP.
- `pri_a15_igrok_cam13` в обеих играх длится 166 кадров / 5,533 секунды.
- Камера `pri_a15_cam_13.anm` побайтно совпадает с оригиналом.
- C++ `animation_movement_controller` рассчитывает root-motion так же, как CoP.
- В Anomaly перед `animpoint:start()` добавлен лишний переход NPC в `idle`.
  Он сбрасывает авторскую позицию и направление анимации. В журнале предыдущей
  версии действительно обнаружено повторное применение абсолютного anchor.
- В Anomaly также закомментирован оригинальный разворот NPC по направлению
  smart-cover во время подхода.

## Что меняет v120

Только для точных участников и smart-cover сцен `jup_b219`/`pri_a15`:

1. `action_animpoint:initialize()` снова работает как в retail CoP:
   `action_base.initialize()` → `animpoint:start()`, без промежуточного `idle`.
2. При физическом подходе возвращён
   `set_desired_direction(smart_direction)` из оригинального CoP.
3. Сохранено поведение v119: активная root-motion сцена не теряет собственный
   animpoint из-за удаления от начальной точки.
4. Сохранено поведение v118: первый движущийся клип получает абсолютный
   авторский anchor, следующие клипы продолжают локальную цепочку.
5. Добавлены редкие переходные записи журнала для initialize/finalize/reach и
   постановки motion в очередь. Покадрового callback или постоянного опроса нет.

Не изменяются модели, OMF, камера, скорость клипа, XFORM, физика, patrol-пути,
координаты smart-cover, звук, трава и тайминги сцен. Путепровод не подменяется
этим animpoint-патчем: там используются walker/path-схемы.

## Проверка

Новая игра, очистка shader cache и пересохранение не нужны. Полностью перезапусти
игру и загрузи сохранение перед нужной сценой.

В логе должны появиться строки:

```text
[anthology/cutscenes-v120] retail CoP action lifecycle active
[anthology/cutscenes-v120] retail initialize npc=...
[anthology/cutscenes-v120] retail reach heading npc=...
[anthology/cutscenes-v120] motion enqueue npc=...
```

Для каждого участника ожидается одна эпоха initialize до завершения его сценовой
цепочки. В частности, `pri_a15_igrok_cam13` должен попасть в очередь один раз.
