# Anthology Performance v105 — RAK Empty Hands Guard

Полная замена патча `Anthology Performance v104 - RAK Indoor Ray Gate`.

Сохранены оптимизации v104: ранняя проверка интервала, один origin на полный
акустический замер и повторное использование таблиц результатов. Дополнительно:

- при пустых руках `env_actorsnd` больше не вызывает `SYS_GetParam` с пустой
  секцией оружия;
- без активного оружия не запускается бессмысленный набор геометрических лучей;
- обработчик выстрела безопасно прекращает работу, если оружие или секция уже
  исчезли во время смены предмета.

Направления лучей, их длина и число отражений, звук и MCM не изменены. Новая
игра не нужна. Одновременно с v105 нельзя включать v104 RAK-патч.

Маркер в логе: `[anthology/v105/rak]`.
