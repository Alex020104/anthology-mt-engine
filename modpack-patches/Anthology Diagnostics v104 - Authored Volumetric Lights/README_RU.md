# Anthology Diagnostics v104 — Authored Volumetric Lights

Чистый A/B-тест локального объёмного света на базе.

- Отключает только SSS-флаг **Force volumetric on all non-directional lights**.
- Обычный свет, динамические тени, солнце, sunshafts и источники, которые авторы явно пометили `volumetric = true`, остаются.
- Интенсивность и выбранное в MCM качество не перезаписываются; меняется только флаг `force-all`.
- Сохранения не меняются, новая игра не нужна. Для применения требуется перезапуск уровня/загрузка сохранения.

Почему это важно: при текущем `volumetric_force=true` каждый теневой point-light может породить до шести shadow/volume-граней, а качество 4 даёт 96 срезов на каждую видимую грань.

Проверка: в логе должна быть строка `[anthology/v104/volumetric-ab]`. Сравнить один и тот же маршрут и время суток. Откат — отключить только этот аддон; SSS снова применит значение MCM при следующем запуске.
