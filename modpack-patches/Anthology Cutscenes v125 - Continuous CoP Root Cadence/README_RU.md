# Anthology Cutscenes v125 — Continuous CoP Root Cadence

Отдельный LTX-патч для двух оригинальных сцен Call of Pripyat:

- спуск к Путепроводу `jup_b219`;
- выход из Путепровода `pri_a15`.

## Что исправлено

v123 запускал `update_npc_logic` непосредственно в переходе на сцену. В Anthology этот эффект в одном кадре трижды обновляет planner и семь раз state manager каждого NPC. Из-за этого первый контроллер root-motion мог создаваться между внеочередными обновлениями, до нормального игрового тика, и получать промежуточный стартовый XFORM.

v125 сохраняет синхронное переключение LTX через `update_obj_logic`, но убирает только внеочередную прокачку planner/state manager. Первый `add_animation` и его root-anchor теперь создаются обычным обновлением NPC, как часть последовательного кадра движка v125.

Координаты patrol, модели, OMF, скорость анимаций, камера, звук, физика, A-Life и сохранения не меняются.

## Проверка

Нужен движок v125. Можно загрузить то же сохранение перед сценой; новая игра и очистка shader cache не требуются. После теста строки `[cop-cadence]` в `xray_*.log` покажут пропуски root-update, IK и расчёта костей для каждого участника.
