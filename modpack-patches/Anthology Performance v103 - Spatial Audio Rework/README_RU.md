# Anthology Performance v103 — Spatial Audio Rework

Отдельная MO2-надстройка над архивом `Spatial_Audio_Rework.xdb0`.

- Сохраняет выбранные в MCM число лучей, число отражений, пресеты и плавную покадровую интерполяцию.
- Акустические лучи и применение полного набора OpenAL EFX ограничены частотой 20 Гц вместо зависимости от FPS.
- Исправляет запись лучей размера помещения в чужой индекс списка оценки закрытости.
- Удаляет оставшийся безусловный диагностический вывод каждые 750 мс.
- Сохранения не меняются. Новая игра не нужна.

Проверка: в логе должна появиться строка `[anthology/v103/sar]`; затем пройти из помещения наружу и обратно, чтобы проверить плавность реверберации. Откат — отключить только этот аддон в MO2.
