# Anthology Performance v138 — Wind Leaves GPU Budget

Отдельный тестовый override для `wind_leaves.script`. Новая игра не требуется.

## Причина

Исходный скрипт постоянно держал снаружи два перекрывающих экран fog-слоя: `p_fog_light` (`nature\\exp_pfx_fog_00`) и `p_fogdust_00` (`nature\\exp_pfx_fogdust_00`). В проблемной сессии после их запуска время `render` выросло примерно с 24,92 до 59,20 мс.

## Что изменено

- Полностью удалено создание и включение только постоянного слоя `p_fog_light`.
- `p_fogdust_00` сохранён как основной постоянный атмосферный слой.
- Погодные листья, насекомые, ночной туман, грозовые эффекты, помещения и подземелья не менялись.
- Защитная отложенная очередь для `mt_particles` не менялась.

## Что проверить

1. Сравнить GPU/render frametime в одной наружной точке при одинаковой погоде и направлении камеры.
2. Проверить, что лёгкая атмосферная пыль `p_fogdust_00` осталась видимой.
3. Проверить смену погоды и времени суток, вход в помещение/подземелье и грозу.
4. Убедиться, что в логе нет ошибок `particles_object`, `ISpatial_DB` и очереди Wind_Leaves.

Для теста модуль должен иметь приоритет выше исходного владельца `wind_leaves.script`. Откат — отключить только этот аддон.
