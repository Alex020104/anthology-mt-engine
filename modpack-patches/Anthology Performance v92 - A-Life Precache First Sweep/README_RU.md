# Anthology Performance v92 — A-Life Precache First Sweep

Тестовый модуль для проверки редких «тиков», найденных профилировщиком v91 в
первом цикле офлайн-A-Life.

## Что изменено

- Во время уже существующего precache движок один раз последовательно обновляет
  весь реестр офлайн-A-Life. Первичная подготовка контролёров, мутантов, отрядов
  и их задач выполняется под загрузочным экраном, а не растягивается на многие
  минуты геймплея отдельными пиками по 20–44 мс.
- После прохода движок восстанавливает обычный бюджет A-Life v88 — 0,090 мс.
  Дистанция 150 м, частота штатной симуляции и сохранение позиций NPC не меняются.
- Это не прогрев мира v70/v71: дополнительного пятсекундного таймера, блокировки
  «Зона ждёт», полноценных кадров мира и скрытого рендера нет.
- Диагностические `mt_frame_profile` и `mt_frame_profile_detail` v91 выключены,
  чтобы таймеры профилировщика не влияли на итоговый FPS.

Новая игра и очистка shader cache не нужны. Проверять нужно на той же сохранённой
игре. Загрузка может стать длиннее на время фактического первого A-Life-прохода;
точное время будет записано в лог.

Ожидаемые маркеры:

```text
* [A-Life/v92] precache first sweep processed N/N objects in X.XX ms; runtime budget restored to 0.090 ms
* [anthology/v92] A-Life precache first sweep active; v91 detail profile disabled
```
