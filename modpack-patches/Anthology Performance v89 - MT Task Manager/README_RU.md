# Anthology Performance v89 - MT Task Manager

Тестовый независимый модуль для проверки `mt_task_manager` на тяжёлом
сохранении Anthology.

Что включено:

- `mt_task_manager 1` переносит `CGameTaskManager::UpdateTasks()` с главного
  потока в существующий игровой MT-поток, работающий параллельно рендеру;
- `lua_use_functor_cache 1` убирает повторный поиск уже загруженных Lua-функций,
  которые используются условиями завершения и провала заданий;
- `mt_ui` принудительно оставлен выключенным: UI, PDA и их коллекции не входят
  в этот тест;
- подробный профайлер оставлен выключенным, чтобы логирование не искажало FPS.

Граница изменения: это менеджер активных заданий игрока, а не весь AI NPC и
не smart-terrain/A-Life. Наибольший эффект ожидается на сохранении с большим
числом активных квестов и тяжёлыми Lua-условиями (в частности, WTF 4.2).

Новая игра и очистка shader cache не нужны. Для сравнения нужен тот же сейв и
тот же маршрут: внутри Скадовска, выход наружу, затем отход от базы без взгляда
на неё. Откат — выключить этот модуль и вернуть `mt_task_manager 0`.
